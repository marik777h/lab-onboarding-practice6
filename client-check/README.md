# Диагностика компьютера. Часть 2

Запустить `pc_info.bat` двойным щелчком в Windows. Отчёт `pc_report.txt` сохранится рядом. Список программ берётся из разделов Uninstall реестра для 32- и 64-битных программ и для текущего пользователя.

## Что проверяется

Для офиса выбрал пять категорий: офисный пакет для документов, браузер для рабочих сайтов, программу для PDF, архиватор для вложений и антивирус. Скрипт показывает, что нашлось, и предлагает варианты для недостающих категорий.

Отдельно ищутся игры и лаунчеры (Steam, Epic Games, Roblox), торрент-клиенты (qBittorrent и uTorrent), мессенджеры (Discord, Telegram, Skype) и программы вроде OBS или Wallpaper Engine. Например, Telegram может использоваться по работе, поэтому решение принимает администратор.

## Проверка

Команда `pc_info.bat --test` проверяет три случая на тестовых списках:

- WinRAR найден, qBittorrent и Telegram попали в список для проверки.
- Если убрать WinRAR из списка, скрипт рекомендует архиватор.
- На пустом списке скрипт пишет, что проверить наличие программ не удалось.

Для проверки на своём ПК запустить батник обычным способом и открыть отчёт. На скриншоте консоли должны быть видны ход проверки и рекомендации.

## Ограничения

Проверка идёт по названиям в реестре. Программы без записи в Uninstall могут не попасть в отчёт. Для Edge и Defender нужно отдельно проверить настройки и состояние защиты. По названию программы нельзя узнать, когда и для чего ей пользовались.
